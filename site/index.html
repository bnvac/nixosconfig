nix²

The Linux for people who build things.

A fast, keyboard-first desktop with the tools for code, circuit boards, microcontrollers and games already set up. Every update can be undone.

install

Two ways in

New computer

Boot the installer from a USB stick. It handles Wi-Fi, the disk and encryption, then asks a few questions.

  1. Download nix2-installer.iso from the latest release
  2. Write it to a 4 GB+ stick with balenaEtcher or Ventoy
  3. Boot from the stick and run:
$ nix2-install

Already on NixOS

Keep your hardware config, clone nix² into /etc/nixos, answer the setup questions and rebuild.

  1. Move your current config aside: sudo mv /etc/nixos /etc/nixos.orig
  2. Run the line below, then sudo nixos-rebuild switch
$ sudo git clone https://github.com/bnvac/nixosconfig /etc/nixos && sudo cp /etc/nixos.orig/hardware-configuration.nix /etc/nixos/ && sudo bash /etc/nixos/pkgs/scripts/setup.sh

Any 64-bit PC from roughly the last ten years, booting in UEFI mode, with internet during the install. AMD and Intel graphics work out of the box; NVIDIA gets NVIDIA's own driver.

features

Set up for building, out of the box

Undo any update

Every update is a new version next to the old ones. Updates pre-build in the background; if one breaks something, switch back.

nix2 rollback

Projects that just build

Rust, Python, C++, Go, Node or a microcontroller board, with the compiler and language server loaded when you cd in.

nix2 new rust

Fast rebuilds

A compile cache and the mold linker for every project, and a notification when a long build finishes.

just watch

Fixes, not error codes

A weekly check of audio, graphics, disk, backups and battery that prints the exact command to fix anything off.

nix2 doctor

Private by default

Firewall on, SSH off, an encrypted disk from the installer, and every app through Tor with one command.

tormode on

Games included

Steam with Proton for every game, Xbox controllers, and a game mode that pauses notifications while you play.

gamemoderun %command%

configuration

One file per machine

Your whole setup is a short file you can read. Change a line and rebuild, and the computer matches it, the same way every time. The installer writes it for you.

  • Switch a feature on or off: mod on virt
  • Drop an app from everything: debloat remove discord
  • Your laptop downloads what your desktop already built
/etc/nixos/settings.local.nix
{
  username = "ada";
  hostName = "workbench";
  timeZone = "Europe/London";
  gpu = "amd";

  modules.virt = true;          # mod on virt
  removePackages = [ "discord" ];
  shareBuilds.serve = true;     # the laptop downloads my builds
}

hardware

Plug in a board. Flash it.

USB permissions, flashing tools and serial monitors come set up, so a board works the moment you plug it in. No sudo, no rules copied from a forum.

  • Raspberry Pi Pico, ESP32, Arduino, STM32 and debug probes
  • QMK and Vial keyboards, logic analysers, SDR radios

questions

Before you install

Is this NixOS?

Yes. nix² is a NixOS configuration with its own tools, defaults and installer on top. Everything NixOS can do still works, and the full NixOS package collection is available.

Do I need to learn Nix?

No. The installer and the menu cover everyday changes, and mod on / mod off switch features. When you want more, your settings file is short and every option is explained next to its default.

What if an update breaks something?

Run nix2 rollback, or pick an older version at boot. Nothing about the old system is overwritten by an update.

Will my graphics card work?

AMD and Intel work with the built-in drivers. With NVIDIA, the installer turns on NVIDIA's own driver; GTX 10-series and older cards use the closed driver instead of the open one.

Is it free?

Yes. nix² is free and open source under the MIT license, and so is everything it installs by default apart from a few drivers and apps that are free to use but closed, like Steam.
