nix2

The Linux for people who build things.

Write code, design circuit boards, flash microcontrollers and play games on a fast, private desktop that sets itself up. Every update can be undone.

Download the installer Source code

Built on NixOS 26.05x86-64 PCsFree, MIT license

What you get

A desktop that stays out of your way

One menu for everything

Every setting, tool and app is one keypress away, sorted by what you want to do.

Super + Alt + Space

Code without setup

New projects come with their compiler, language server and formatter. A compile cache and a fast linker are on for every build.

nix2 new rust

Undo any update

Updates are pre-built in the background. If one breaks something, go back to the version that worked.

nix2 rollback

Fixes, not error codes

A weekly check looks at audio, graphics, disk, backups and battery, and tells you the exact fix when something's off.

nix2 doctor

Private by default

Firewall on, SSH off, an encrypted disk from the installer, and Tor for everything when you want it.

tormode on

Games included

Steam with Proton for every game, controller support, and a game mode that pauses notifications while you play.

gamemoderun %command%

Hardware

Plug in a board. Flash it.

USB permissions, flashing tools and serial monitors are already set up, so a new board works the moment you plug it in. No sudo, no udev rules to copy from a forum.

Install

Three steps, about half an hour

  1. Download

    Get nix2-installer.iso from the latest release.

  2. Make a USB stick

    Write it to a 4 GB+ stick with balenaEtcher, Ventoy or dd.

  3. Boot and install

    Start from the stick and type nix2-install. It connects to Wi-Fi, asks a few questions and does the rest.

Needs a 64-bit PC from about the last ten years, booting in UEFI mode, with internet for the install. AMD and Intel graphics work out of the box; NVIDIA gets NVIDIA's own driver. Already on NixOS? Clone the repo into /etc/nixos and run nix2-setup.
