nix2

A Linux for people who build things.

Your whole computer is one expression. Evaluate it and you get the same system every time, with every earlier version still there to go back to. On top: tools for code, circuit boards, microcontrollers and games, ready when you log in.

§1

Properties

Six things that hold on every nix² machine, each with the command that proves it.

Theorem 1 (Rollback)

Every update can be undone.

Proof. Each update is a new version next to the old ones. Updates build in the background; if one breaks something, switch back.

nix2 rollback

Theorem 2 (Hardware)

A board works the moment it's plugged in.

Proof. USB permissions for Pico, ESP32, Arduino, debug probes and QMK keyboards ship with the system. No sudo, no forum rules to copy.

nix2 serial

Theorem 3 (Projects)

A new project builds on the first try.

Proof. Its compiler, language server and formatter load when you cd in. A compile cache and the mold linker keep rebuilds short.

nix2 new rust

Lemma 4 (Diagnosis)

Common problems come with their fix.

Proof. A weekly check covers audio, graphics, disk, backups, battery and temperature, and prints the exact command to run.

nix2 doctor

Lemma 5 (Privacy)

Nothing is open that you didn't open.

Proof. Firewall on, SSH off, disk encryption in the installer, and Tor for all traffic with one command.

tormode on

Corollary 6 (Games)

Windows games run through Steam.

Proof. Proton is on for every title, controllers pair over Bluetooth, and game mode pauses notifications while you play.

gamemoderun %command%

Installation

install = boot∘write∘download

  1. (i)

    Download

    nix2-installer.iso from the latest release on GitHub.

  2. (ii)

    Write

    Put it on a 4 GB+ USB stick with balenaEtcher, Ventoy or dd.

  3. (iii)

    Boot

    Start from the stick and type nix2-install. It connects to Wi-Fi, asks a few questions and does the rest in about half an hour.

Needs a 64-bit PC from roughly the last ten years, booting in UEFI mode, and internet during the install. AMD and Intel graphics work out of the box; NVIDIA gets NVIDIA's own driver. Already on NixOS? Clone the repo into /etc/nixos and run nix2-setup.
