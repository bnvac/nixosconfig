Make it yours

Wallpapers that move, snow that falls

Pick from six built-in wallpapers or your own pictures, choose how they fit, and shuffle. Own Wallpaper Engine on Steam? Its animated wallpapers play on every screen.

  • Live wallpapers from the Steam Workshop, muted and paused while you game
  • Falling snow drifts behind your windows; switch it off any time
  • Super+Alt+W opens the picker from anywhere

One menu

Everything is one keypress away

Super+Alt+Space opens a menu of everything your computer can do, sorted by what you want: updates, apps, projects, games, devices, privacy.

  • Type to search, Backspace to go back, Escape to close
  • Add your own entries in a plain text file, no rebuild
  • Clipboard history, screenshots and the lock screen on their own keys

Know your machine

neofetch, made for nix²

A clean system summary with the details that matter here: which system version you're on and can roll back from, and which features are switched on.

  • Type neofetch or press Super+Alt+I

Code and hardware

Plug in a board. Flash it.

Start a project for a Pico, ESP32 or Arduino with its tools ready, then build, flash and watch its serial output from one terminal. No sudo, no permission rules to copy from a forum.

  • nix2 new for Rust, Python, C++, Go, Node, PlatformIO boards and MicroPython
  • Fast rebuilds: a compile cache and the mold linker for every project
  • KiCad, FreeCAD, OpenSCAD and OrcaSlicer installed, QMK and Vial keyboards supported

One file per machine

Your whole setup, in a file you can read

Change a line and rebuild, and your computer matches it, the same way every time. The installer writes it for you, and updates never touch it.

  • Switch a feature on: mod on virt
  • Drop an app from everything: debloat remove discord
  • Copy the file to a new machine and get the same system
/etc/nixos/settings.local.nix
{
  username = "ada";
  hostName = "workbench";
  timeZone = "Europe/London";
  gpu = "amd";

  modules.virt = true;          # mod on virt
  removePackages = [ "discord" ];
  shareBuilds.serve = true;     # the laptop downloads my builds
}

Install

Two ways to get nix²

recommended

New computer

Boot the installer from a USB stick. It sets up Wi-Fi, the disk and encryption, then asks a few questions.

  1. Download nix2-installer.iso from the latest release
  2. Write it to a 4 GB+ stick with balenaEtcher or Ventoy
  3. Boot from the stick and run:
$ nix2-install
already on NixOS

Existing NixOS

Keep your hardware config, clone nix² into /etc/nixos, answer the setup questions and rebuild.

  1. Move your config aside: sudo mv /etc/nixos /etc/nixos.orig
  2. Run the line below, then sudo nixos-rebuild switch
$ sudo git clone https://github.com/bnvac/nixosconfig /etc/nixos && sudo cp /etc/nixos.orig/hardware-configuration.nix /etc/nixos/ && sudo bash /etc/nixos/pkgs/scripts/setup.sh

Needs a 64-bit PC from roughly the last ten years, booting in UEFI mode, with internet during the install. AMD and Intel graphics work out of the box; NVIDIA gets NVIDIA's own driver.

Questions

Before you install

Is this NixOS?

Yes. nix² is a NixOS configuration with its own tools, defaults and installer on top. Everything NixOS can do still works, and all of nixpkgs is available.

Do I need to learn Nix?

No. The installer and the menu cover everyday changes, and mod on / mod off switch features. When you want more, your settings file is short and every option is explained next to its default.

What if an update breaks something?

Run nix2 rollback, or pick an older version at boot. Updates never overwrite the old system.

Does Wallpaper Engine work?

Yes, if you own Wallpaper Engine on Steam: install it (Steam Play is on, so the Windows app installs), subscribe to wallpapers, and they show up in the Live tab of the wallpaper picker.

Will my graphics card work?

AMD and Intel work with the built-in drivers. With NVIDIA, the installer turns on NVIDIA's own driver; GTX 10-series and older cards use the closed driver instead of the open one.

Is it free?

Yes. nix² is free and open source under the MIT license. A few things it can install, like Steam and the NVIDIA driver, are free to use but closed source.

Ready to build something?

One USB stick and about half an hour.
